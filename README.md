# Справочник по Git и GitHub

Учебное издание. Автор — Макаров Максим Николаевич.

Книга-сайт о работе с Git через панель Source Control в Visual Studio Code и об
углублённой работе с GitHub: задачи и pull request, канбан-доска в Projects,
публикация сайта через Pages, автоматические проверки в Actions и настройки
репозитория.

## Устройство

```
index.html          обложка и содержание: модули, главы, состояние
styles.css          типографика и блоки глав (лента лет, досье, витрина, схемы)
book.js             увеличение картинок, подсветка событий на ленте лет
temy/NN-slug/       главы, картинки главы лежат в её же папке img/
tools/images.py     скачивание иллюстраций с Викисклада вместе с лицензией
PLAN.md             карта книги: модули, порядок тем, правила оформления
```

Сайт статический: открывается двойным кликом по `index.html`, публикуется на
GitHub Pages как есть, без сборки.

## Картинки

Иллюстрации берутся с Wikimedia Commons скриптом `tools/images.py`: он кладёт
файл в `temy/<глава>/img/` и записывает автора, лицензию и ссылку на страницу
файла в `img/credits.json`. Под каждой картинкой в главе стоит подпись с этими
данными — без неё книгу нельзя публиковать.

```bash
python3 tools/images.py search "Linus Torvalds"   # подобрать имя файла
```

Скриншоты VS Code и GitHub снимаются отдельно, на учебной машине.
