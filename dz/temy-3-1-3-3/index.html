Кофейня «Зерно»: ветки, переключение и слияние

Задание проходит по темам 3.1–3.3 на одном проекте. Часть 1 — как Git хранит ветку. Часть 2 — ветка для десертов и переключение между ветками. Часть 3 — два вида слияния и удаление веток. Сдаётся документ Word со снимками экрана и ответами на вопросы.

Отправка коммитов и веток — модуль 4. Работа выполняется только на вашем компьютере и сдаётся снимками экрана. Прав на запись в учебный репозиторий у вас нет, поэтому кнопки Sync Changes и Publish Branch оставьте как есть: отправка закончится ошибкой.

Нужен новый клон

Задание рассчитано на исходные пять коммитов проекта. Клоны из ДЗ 1 и ДЗ 2 оставьте на месте: для ДЗ 3 создаётся отдельная папка.

Как делать снимки

  • Снимается окно VS Code целиком, текст должен читаться.
  • Снимок в буфер обмена: Windows — Win + Shift + S; macOS — Cmd + Ctrl + Shift + 4, затем пробел и щелчок по окну.
  • Под каждым снимком в Word — подпись из оранжевой рамки задания.
  • Терминал: Ctrl + ` (клавиша «ё»). Длинный ответ, который не помещается в окно, снимается двумя снимками под одним номером.
  • Имена коммитов (хеши) у вас будут свои. Совпадут только имена пяти исходных коммитов проекта: 69a4f0b, c971be5, 07b88ef, c016d04, d451256.
  • Перед каждым коммитом посмотрите на имя ветки в строке состояния внизу слева: коммит попадёт в эту ветку.

3Слияние

Глава 3.3. Сначала в main сливается короткая ветка с адресом кофейни — Git просто перенесёт имя ветки вперёд. Затем сливается ветка десертов, которая разошлась с main, — Git создаст коммит слияния.

Шаг 1. Короткая ветка с адресом

Перейдите на main. Затем в списке веток Create new branch… → имя adres.

В index.html под телефоном добавьте адрес:

Сохраните, отберите плюсом и сделайте коммит Добавил адрес кофейни.
