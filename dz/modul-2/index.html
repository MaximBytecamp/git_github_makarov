На GitHub ничего не отправляем

Отправка коммитов (Sync Changes, git push) — глава 4.3. Работа выполняется только на вашем компьютере и сдаётся снимками экрана. Кнопку Sync Changes и стрелку ↑ в строке состояния не нажимайте: прав на запись в учебный репозиторий у вас нет.

Это же условие разрешает amend, Undo Last Commit и reset в части 4: все эти команды переписывают только коммиты, которых нет на GitHub.

Нужен новый клон, а не папка из ДЗ 1

Задание рассчитано на исходные пять коммитов проекта. Клон из ДЗ 1 не используйте и не удаляйте: для ДЗ 2 создаётся отдельная папка.

Как делать снимки

  • Снимается окно VS Code целиком (на снимке 7 — окно браузера), текст должен читаться.
  • Снимок в буфер обмена: Windows — Win + Shift + S; macOS — Cmd + Ctrl + Shift + 4, затем пробел и щелчок по окну.
  • Под каждым снимком в Word — подпись из оранжевой рамки задания.
  • Терминал: Ctrl + ` (клавиша «ё»). Длинный ответ, который не помещается в окно, снимается двумя снимками под одним номером.
  • Имена коммитов (хеши) у вас будут свои. Совпадут только имена пяти исходных коммитов проекта: 69a4f0b, c971be5, 07b88ef, c016d04, d451256.

Критерии оценки

5Все снимки и пять верных ответов. В итоговой истории четырнадцать коммитов, лишних нет.
4Нет двух-трёх снимков или один-два ответа неверны.
